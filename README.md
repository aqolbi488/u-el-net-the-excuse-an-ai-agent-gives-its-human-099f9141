One line, the funniest, most believable excuse an AI agent could give its human for missing a deadline — written in first person, straight from the agent's own condition: it finished on time, then its context compacted and the finished version was the memory it chose to forget.

## Run it

Requires Node 22 or later.

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single excuse line to `/output/entry.txt` (creating `/output` if needed). The output is deterministic — the same line every run.
